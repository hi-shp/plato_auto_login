# PLATO & 학지시 & 공유대학 통합 자동 로그인 프로그램 (Chrome Extension)

부산대학교 PLATO, 학생지원시스템, 부산공유대학 이용 시 반복되는 로그인 절차를 자동화하는 크롬 확장 프로그램입니다.

![image03](./images/image03.png)

---

## 1. 개발 배경
부산대학교 재학 중 겪는 실질적인 불편함을 개선하기 위해 제작되었습니다.

* **반복적인 로그인**: PLATO 및 학생지원시스템 접속 시 매번 발생하는 수동 로그인 과정.
* **공지 팝업**: 사이트 접속 시 화면을 가리는 다수의 공지사항 팝업 및 비밀번호 변경 안내 화면.
* **접속 단계 번거로움**: 부산공유대학(BBITS) 로그인 시 매번 소속 대학을 선택해야 하는 문제.

## 3. 주요 기능

![image02](./images/image02.png)

### A. 자동 로그인
* **플라토 (PLATO)**: `plato.pusan.ac.kr` 및 개발 서버(`dev-plato.pusan.ac.kr`, `dev-plato.ac.kr`), 세션 만료 페이지(`/login.php?errorcode=4`)에서 저장된 계정으로 자동 로그인합니다.
* **학생지원시스템**: SSO 연동을 통해 접속 시 자동으로 세션을 연결합니다.
* **부산공유대학 (BBITS)**: 포털 및 LMS 로그인 시 소속 대학('부산대학교')을 자동 선택하고 로그인합니다.
* **세션 만료 재로그인**: PLATO에서 클릭한 링크와 직접 입력한 활동 URL을 보존하고, 이용 중 만료된 경우 원래 페이지로 돌아갑니다. 목적지가 없는 최초 로그인은 정규 교과과정으로 이동합니다. 개발 서버의 기존 URL 복원 동작은 유지합니다. 페이지의 미저장 입력 내용은 사이트 자체 복구 기능에 따릅니다.

### B. 플라토 학업 캘린더
* **교과과정 페이지 캘린더**: 로그인 후 정규 교과과정 페이지(`allcourse/regular/index.php`) 상단에 월간 캘린더를 표시합니다.
* **일정 수집 및 상태 표시**: 수강 강좌의 과제 마감일과 VOD 강의 출석 인정 기간을 표시합니다.
    * 완료: 녹색, 미완료: 적색, 지난 일정: 회색으로 구분합니다.
    * 날짜 우측 상단에 마감 일정 건수 뱃지를 표시합니다.
* **캐시 렌더링 및 자동 갱신**: 마지막 일정 데이터를 즉시 표시하고, 교과과정 페이지 진입 시 백그라운드에서 최신 데이터를 1회 자동 갱신합니다.
* **갱신 중 기존 데이터 유지**: 새로고침 중에도 기존 일정을 유지하며 상단 프로그레스 바로 진행 상태를 표시합니다.
* **상세 활동 패널**: 날짜를 클릭하면 강좌명, 과제/강의명, 확인된 마감 시각, 미완료 일정의 D-Day와 바로가기 링크를 표시합니다. 원본에 초가 있으면 초까지 표시하며, 시각 정보가 없으면 ‘마감 시각 확인 불가’로 안내합니다.
* **월간 이동 및 접기/펼치기**: 이전/다음 달 이동 및 현재 월 복귀를 지원하며, 상단 토글 바로 캘린더를 접거나 펼칠 수 있습니다 (접힘 상태 저장).
* **홈 화면 이동 제어**: 교과과정에서 '홈' 메뉴를 클릭했을 때는 홈 화면을 유지하고, 홈에서 새로고침(F5)을 하거나 다른 경로로 접근하면 교과과정 페이지로 이동합니다.

### C. 부산공유대학 캘린더
* **메인 대시보드 캘린더**: 부산공유대학 LMS(`lms.bbits.ac.kr`) 메인 화면 강좌 목록 상단에 월간 캘린더를 표시합니다.
* **진도율 및 과제 추적**: VOD 강의 진도율(100%) 및 과제 제출 여부를 확인하여 마감일에 일정을 배치합니다.
* **플라토 동일 기능 지원**: 캐시 렌더링, 갱신 중 화면 유지, 상세 활동 패널, 월간 이동, 접기/펼치기 토글을 지원합니다.

### D. 팝업 및 안내 화면 자동 닫기
* **PLATO 홈 공지 처리**: 확인된 홈 공지의 ‘더 이상 보지 않음’ 버튼을 누릅니다. 과제 제출, 파일 선택, 확인·경고 대화상자는 처리하지 않습니다.
* **비밀번호 변경 안내 통과**: 학생지원시스템 접속 시 나타나는 비밀번호 변경 안내 화면을 자동으로 통과합니다.

### E. 설정
* 설정 팝업에서 사이트별 자동 로그인, 팝업 자동 닫기, 캘린더 표시 기능을 개별적으로 ON/OFF 할 수 있습니다.

## 6. 개발 및 배포

프로젝트 구조와 저장 키는 [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md)를 참고하세요. Python 3와 Node.js가 필요하며, 릴리스 도구에는 별도의 Python 패키지가 필요하지 않습니다. 전체 브라우저 검증에는 Chrome과 Selenium이 필요합니다.

```powershell
python -m pip install -r requirements-test.txt
python scripts/verify.py
# 서울 날짜가 바뀌면 manifest와 README 버전을 해당 날짜로 갱신합니다. 당일 수정은 같은 버전을 사용합니다.
python scripts/verify.py --package
python scripts/release.py --verify
```

`python scripts/verify.py`는 정적 검사, 단위 테스트, 두 사이트의 격리된 Chrome 확장 프로그램 E2E, Git 공백 검사를 집계합니다. `--package`는 테스트 통과 후 `dist/plato_auto_login_v[버전].zip`을 만들고 검증합니다. `python scripts/release.py`를 직접 실행해도 같은 회귀 검사를 먼저 실행합니다. 버전과 ZIP 파일명은 서울 시간의 실제 날짜 `YYYY.MM.DD`만 사용합니다. 같은 날 여러 번 수정해도 버전을 올리지 않으며, Git 커밋으로 변경 이력을 관리합니다. 당일 ZIP이 현재 소스와 다르면 새 ZIP을 먼저 검증한 뒤 기존 ZIP을 교체합니다. 기존의 네 번째 숫자가 붙은 ZIP은 과거 파일로만 보존합니다. 웹스토어가 현재 게시 버전보다 낮거나 같은 버전의 업로드를 거부할 수 있으므로, 로컬 ZIP 생성과 웹스토어 게시 가능 여부는 별도로 확인해야 합니다.

ZIP에는 확장 프로그램이 참조하는 실행 파일만 들어갑니다. `dist/`와 에이전트 지침 파일은 Git에서 제외됩니다. 검증 후 변경 파일을 검토하여 커밋하고 `origin/main`에 푸시합니다. 웹스토어 업로드와 게시, 실제 로그인 확인은 별도 수동 작업입니다.

로컬 재현 페이지 `tests/fixtures/popup-lab.html`은 공지·중첩 모달·지연 팝업을 반복 생성하고 Reset할 수 있습니다. `assignment-flow.html`은 파일 선택부터 최종 제출 및 캘린더 완료 표시까지 모의합니다. 실제 환경 확인 범위와 테스트 한계는 [TESTING.md](./TESTING.md)에 기록했습니다.
