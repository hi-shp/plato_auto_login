# PLATO & 학지시 & 공유대학 통합 자동 로그인 프로그램 (Chrome Extension)

부산대학교 PLATO, 학생지원시스템, 부산공유대학 이용 시 발생하는 반복적인 로그인 절차를 자동화하는 도구입니다.

![image03](./images/image03.png)

---

## 1. 개발 배경
본 프로그램은 부산대학교 조선해양공학과 학부생으로서 대학 생활 중 겪는 실질적인 불편함을 개선하기 위해 기획되었습니다.

* **반복적인 인증 요구**: PLATO 및 학생지원시스템 접속 시마다 발생하는 수동 로그인 과정의 비효율성.
* **불필요한 인터페이스 노출**: 사이트 접속 시 화면을 가리는 다수의 공지사항 팝업 및 주기적인 비밀번호 변경 안내 화면.
* **접속 단계의 복잡성**: 부산공유대학(BBITS) 로그인 시 매번 소속 대학을 선택해야 하는 번거로움.

이러한 요소들을 자동화 로직으로 처리하여 시스템 접근 시간을 단축하고 사용 편의성을 높이고자 하였습니다.

## 2. 개발 및 업데이트 과정
기존의 단순한 입력 보조 도구에서 시작하여, 사용자 보안과 다양한 플랫폼 지원을 목표로 고도화하였습니다.

* **초기 버전**: PLATO 자동 로그인 및 팝업 닫기 기능 구현.
* **중기 버전**: 학생지원시스템(Onestop) 및 부산공유대학(BBITS) 연동 지원 확대.
* **최신 버전 (v2026.09.04)**: 
    * 2026년도 PLATO UI 전면 개편(Coursemos 신규 테마)에 따른 로그인 구조 대응.
    * PLATO 접속 시 로그인 페이지 자동 전환 및 Bouncer 유효성 검사기 호환 자동 로그인 구현.
    * PLATO 개발/테스트 서버(`dev-plato.pusan.ac.kr`, `dev-plato.ac.kr`) 및 세션 만료 페이지(`/login.php?errorcode=4`) 자동 로그인 지원.
    * **PLATO 로그인 시 홈 화면 대신 '정규 교과과정 페이지'로 자동 이동 지원**.
    * **교과과정 페이지 최상단 '스마트 학업 캘린더' 대시보드 위젯 탑재**:
        * 이번 달 전체 과제 및 동영상 강의(VOD) 마감일정 월간 캘린더 통합 뷰 제공.
        * **마지막 일정 기록 즉시 렌더링**: 사이트 접속 시 로컬 캐시를 읽어 하얀 빈 화면 없이 기존 캘린더를 즉각 표시.
        * **교과과정 페이지 접속 시 자동 1회 새로고침**: 페이지 진입 시마다 백그라운드에서 최신 일정을 자동 동기화.
        * **새로고침 중 기존 일정 화면 유지**: 갱신 중에도 일정이 하얗게 사라지지 않고 기존 데이터를 그대로 둔 채 상단 슬라이딩 프로그레스 바 및 3단 펄스 도트로 세련되게 로딩 표시.
        * 과제 제출 완료 여부(`제출 완료`/`미제출`) 및 VOD 학습 완료 상태(`완료`/`미완료`) 실시간 추적 및 뱃지/컬러 표기.
        * 일자 클릭 시 하단에 상세 활동 패널 노출 (강좌명, 교수님 성함, 과제/강의명, 학습/제출 인정 기간, D-Day 뱃지, 바로가기 링크).
        * 이전/다음 달 전체 월간 일정 자유 탐색 및 중앙 연월 클릭 시 현재 월 즉시 복귀.
        * 캘린더 전체(헤더, 그리드, 상세 패널) 접기/펼치기 가로형 토글 바 및 상태 영구 보존(`chrome.storage.local`).
        * 병렬 비동기 통신(`Promise.all`) 기반의 초고속 실시간 데이터 동기화.
        * 확장 프로그램 설정 팝업에서 캘린더 기능 원클릭 ON/OFF 토글 지원.
    * 장시간 미사용 시 발생하는 세션 만료 감지 및 자동 재로그인 기능 추가 (작업 중이던 URL 보존).
    * Bootstrap 5 신규 공지 팝업 자동 닫기 셀렉터 대응.
    * **부산공유대학 LMS(`lms.bbits.ac.kr/login.php`) 자동 로그인 및 부산대학교 소속 자동 선택 지원 확대**.
* **이전 버전**: 
    * 크롬 확장 프로그램 표준인 **Manifest V3**로 완전 전환.
    * 데이터 저장 방식을 브라우저 전용 보안 저장소(`chrome.storage.local`)로 변경하여 보안성 강화.
    * 학생지원시스템 비밀번호 변경 안내 화면 자동 통과 로직 반영.

## 3. 주요 기능 명세

![image02](./images/image02.png)

### A. 통합 자동 로그인 (Auto-Login)
* **PLATO & 개발서버(dev-plato)**: `plato.pusan.ac.kr` 및 개발/테스트 서버(`dev-plato.pusan.ac.kr`, `dev-plato.ac.kr`) 접속 시 세션 만료 페이지(`/login.php?errorcode=4`)를 포함하여 저장된 동일한 계정 정보로 자동 로그인을 지원합니다.
* **학생지원시스템**: 통합 로그인(SSO) 연동을 통해 별도의 조작 없이 세션을 연결합니다.
* **부산공유대학(BBITS 포털 & LMS)**: 포털(`www.bbits.ac.kr`) 및 LMS(`lms.bbits.ac.kr`) 로그인 시 소속 대학('부산대학교')을 자동으로 선택하고 계정 정보를 입력하여 원스톱 로그인을 지원합니다.

### B. 플라토 스마트 학업 캘린더 (Smart Calendar Dashboard)
* **교과과정 대시보드 자동 마운트**: PLATO 로그인 후 정규 교과과정 페이지(`allcourse/regular/index.php`) 상단에 고정 7열 대형 월간 캘린더 대시보드가 자동으로 렌더링됩니다.
* **마지막 기록 즉시 렌더링 & 페이지 진입 시 자동 새로고침**:
    * 브라우저 로컬 스토리지에 저장된 마지막 학업 일정 데이터를 페이지 진입 즉시 렌더링하여 화면 깜빡임이나 하얀 빈 화면 대기 시간 없이 즉시 캘린더를 확인할 수 있습니다.
    * 교과과정 페이지에 접속할 때마다 백그라운드에서 자동으로 1회 새로고침을 진행하여 항상 최신 과제 및 강의 상태를 실시간으로 맞춥니다.
* **새로고침 중 기존 일정 유지 및 경량 로딩 UI**:
    * 새로고침이 진행되는 동안 기존 일정을 하얗게 비우지 않고 화면에 그대로 보존하여 시각적 연속성을 유지합니다.
    * 상단 슬라이딩 프로그레스 바와 중앙 3단 펄스 도트 인디케이터가 반투명 블러 오버레이 위에 가볍게 표시되어 방해 없는 부드러운 갱신 피드백을 전달합니다.
* **학업 일정 통합 수집 및 상태 추적**:
    * 이번 학기 수강 중인 모든 강좌의 과제 마감일 및 동영상 강의(VOD) 출석 인정 기간을 하나의 캘린더에 통합 표시합니다.
    * 실제 과제 제출 여부(`제출 완료`/`미제출`) 및 동영상 시청 완료 상태(`완료`/`미완료`)를 실시간 대조하여 칩 색상으로 직관적 구분합니다 (완료: 녹색, 미완료 마감: 적색, 지난 마감: 회색).
    * 날짜 셀 우측 상단에 마감 일정 건수 카운트 뱃지를 제공합니다.
* **인터랙티브 일자별 상세 활동 패널**:
    * 캘린더 내 특정 날짜를 클릭하면 하단에 상세 패널이 펼쳐지며 해당 일자의 세부 활동 목록이 노출됩니다.
    * 강좌명 및 담당 교수님 성함, 과제/강의명, 학습/제출 인정 기간(요일 포함), 마감 D-Day 뱃지(`오늘 마감`, `D-1` 등), 해당 학습 활동으로 즉시 이동하는 바로가기 버튼을 제공합니다.
* **월간 네비게이션 및 현재 월 복귀**:
    * 이전 달(`<`) 및 다음 달(`>`) 이동 버튼을 통해 학기 전체 월별 일정을 유연하게 탐색할 수 있습니다.
    * 중앙의 'YYYY년 M월' 텍스트를 클릭하면 오늘이 포함된 현재 월로 즉시 복귀합니다.
* **캘린더 접기/펼치기 토글 바**:
    * 상단 가로형 토글 바를 통해 캘린더 전체(헤더, 그리드, 상세 패널)를 손쉽게 접거나 펼칠 수 있습니다.
    * 접힘/펼침 상태는 로컬 스토리지에 자동 저장되어 페이지 새로고침이나 재접속 시에도 유지됩니다.
* **초고속 병렬 동기화**:
    * 강좌별 활동 현황과 Moodle 캘린더 데이터를 `Promise.all` 기반 병렬 비동기 통신으로 일괄 조회하여 갱신 시간을 대폭 단축했습니다.

### C. 팝업 및 안내 자동 처리
* **공지 팝업 관리**: 각 사이트의 공지사항 팝업창을 자동으로 닫거나 화면에 표시되지 않도록 차단합니다.
* **변경 안내 무시**: 학생지원시스템 로그인 시 주기적으로 나타나는 '비밀번호 변경 안내' 팝업을 감지하여 자동으로 통과 처리합니다.

### D. 사용자 편의 기능
* **사이트별 개별 설정**: 설정 팝업 창을 통해 각 사이트별 자동 로그인 및 팝업 차단 활성화 여부를 독립적으로 관리할 수 있습니다.
* **스마트 캘린더 ON/OFF 설정**: 설정 팝업에서 '플라토 스마트 캘린더' 기능을 끄면 대시보드 위젯 및 홈 화면에서의 교과과정 자동 이동이 비활성화되어 기본 PLATO 순정 화면으로 이용할 수 있습니다.

## 4. 데이터 보안 및 정책
* 모든 계정 정보는 사용자의 브라우저 내부 보안 저장소(`chrome.storage.local`)에만 국한되어 저장됩니다.
* 입력된 정보는 어떠한 경우에도 외부 서버로 전송되거나 공유되지 않으며, 오직 로컬 환경 내에서만 관리됩니다.
